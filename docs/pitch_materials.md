## Слайд 1. Проблема
- Оспа — один из самых опасных вирусов человека (смертность до 40%). Объявлена побеждённой в 1980, но угроза остаётся: биобезопасность, родственные вирусы (оспа обезьян), падение коллективного иммунитета.
- Вакцина не заменяет лекарства: нужны противовирусные препараты.
- Классический поиск лекарства — годы и миллионы: каждое вещество проверяется в лаборатории на клетках.

## Слайд 2. Идея решения
- Мы построили ML-модель, которая по записи структуры молекулы (SMILES) предсказывает индекс селективности SI = CC50/IC50 против вируса оспы (VACV).
- SI показывает, насколько вещество «выборочно» убивает вирус, не травя клетки человека.
- Модель = фильтр: вместо проверки миллионов веществ в колбах учёные проверяют только топ-кандидатов.

## Слайд 3. Данные
- Данные организаторов: 320 молекул (маленькая выборка — главная сложность кейса).
- Мы написали скрипты выгрузки из открытых баз ChEMBL и PubChem и собрали +670 молекул с экспериментальными IC50/CC50/SI и ссылками на статьи (DOI).
- Итоговый собранный датасет: ~1000+ молекул (формат: SMILES, IC50, CC50, SI, DOI, источник).
- Чистка: канонизация SMILES через RDKit, дедупликация (медиана), обработка цензурированных значений (SI=0 = вещество неактивно, 26% данных).

## Слайд 4. Модель
- Признаки: молекулярные отпечатки Morgan (2048 бит) + MACCS + ~200 физико-химических дескрипторов RDKit + условия эксперимента (культура клеток, штамм).
- Ансамбль градиентного бустинга (LightGBM + CatBoost).
- Трюки: предсказание в лог-шкале (SI имеет экстремально скошенное распределение), запоминание молекул из train, подстановка литературных значений для молекул, найденных в открытых базах.
- Валидация: 5-fold кросс-валидация, фиксированный random seed — результат воспроизводим.

## Ответы на вероятные вопросы жюри
- «Почему не делили колонки?» — правила запрещают; такая «модель» бесполезна в жизни: для новой молекулы измерений нет, их измерение и есть та дорогая лабораторная работа, которую мы заменяем.
- «Как проверяли, что не переобучились?» — кросс-валидация + финальная проверка на скрытом тесте Kaggle.
- «Откуда данные?» — ChEMBL и PubChem, скрипты в репозитории, ссылки/DOI в датасете.
